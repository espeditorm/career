## A vaga
A Objective é uma consultoria de software com escritórios em São Paulo e Chicago e atuação remota. A vaga é de UI/UX para aplicações web de um cliente
global: wireframes, fluxos, protótipos e UI de alta fidelidade no Figma, design system, acessibilidade, handoff e documentação.
**Contrato de 3 meses** (projeto pontual, 160 h/mês), com possibilidade de continuidade, em **PJ ou CLT**. Inglês avançado/fluente obrigatório.

**Etapas publicadas:** Inscrição → Fit cultural → **Entrevista técnica + live coding** → Entrevista com o cliente → Contratação.

**Salário:** não publicado. Pretensão: R$ 26.000 PJ ou R$ 23.000 CLT.

**Atenção:** é um projeto de 3 meses e tem **live coding** (provavelmente HTML/CSS básico, que eles citam como diferencial). Pratique um pouco antes.
