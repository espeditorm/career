- **XP:** CPF (campo obrigatório).

### Pontos de atenção
- Nenhuma das 7 vagas publica salário. As pretensões seguem `00_BASE/respostas_padrao.md` (acima do piso).
  Se na triagem a faixa vier abaixo de US$ 4.000 / R$ 20.400, dá para encerrar ali.
- **Truelogic** exige protótipos funcionais feitos com ferramentas de código com IA (Cursor, Claude Code).
  Isso não está no currículo; ela fica atrás das outras por isso.
- Nenhum formulário tem campo de carta de apresentação, por isso não há `cover_letter.txt` nesta rodada.
